# シャトルラン ワードバトル

20mシャトルランの音源に合わせて、回数(往復)ごとにお題の単語を答えていく対戦ゲームです。
2回連続で正解できないと脱落、音源が終了した時点で生存している人が勝者になります。

## 起動方法

1. Node.js (18以上推奨) をインストール
2. このフォルダで依存パッケージをインストール
   ```
   npm install
   ```
3. サーバーを起動
   ```
   npm start
   ```
4. ブラウザで `http://localhost:3000` を開く(参加者は同じネットワーク内の別デバイスから、サーバーPCのIPアドレスでアクセスしてください。例: http://192.168.x.x:3000)

## 使い方

1. 1人が「部屋を作る」でニックネームを入力し部屋を作成 → 4桁の部屋コードが発行されます
2. 他の参加者は「部屋に入る」からニックネームと部屋コードを入力して入室(最大10人)
3. 全員そろったらホストが「ゲームスタート」を押す
4. 5秒前カウントダウン後、シャトルラン音源が自動再生され、回数・レベルに応じて出題が進みます
5. 各参加者は自分の入力欄にお題(山形県新庄市に関係する物)に沿った単語を入力し、Enterキーまたは「確定」ボタンで判定
   - 正解 → その回は入力欄が消える
   - 不正解 → 同じ回のうちにもう一度入力し直せる(何度でも可、ただし記録されるのは最終結果)
   - 一度使った単語や、表記ゆれレベルで似すぎている単語(例:わらすこ広場/わらす子広場)は再使用不可
   - 2回連続でその回に正解できないと脱落
6. 音源(22分15秒、247回・レベル22まで)が終了した時点で生存者が勝者です

## ファイル構成

- `server.js` … ゲームサーバー本体(Express + Socket.IO)。部屋管理・回数/レベル進行・正誤判定・脱落判定を行うサーバー権威型の設計です。
- `levelTable.js` … 20mシャトルランの標準的な速度モデルをもとに、実際の音源長(1335.048秒)に正規化したレベル・回数テーブルを生成します。
- `wordUtils.js` … 表記ゆれの正規化、正誤判定、類似単語(既出単語との重複)判定ロジック。
- `public/` … クライアント側(HTML/CSS/JS)、音源(audio.mp3)、お題データ(themes.json)。

## お題データの追加・編集

`public/themes.json` を編集してください。「お題を今後さらに追加する」とのことでしたので、下記のように `themes` 配列に項目を追加すれば、複数テーマを用意できます(現状は `server.js` 内で `themeId: 1` を固定で使用しているので、選択式にする場合はロビー画面の改修が必要です。ご要望があれば追加対応します)。

```json
{
  "id": 2,
  "name": "新しいお題名",
  "answers": ["解答例1", "解答例2"]
}
```

## 注意点・既知の制約

- 音源とレベル進行の同期は「サーバーのタイマー」を正としており、各クライアントの音源再生はゲーム開始と同時にローカルで再生を開始する方式です。ネットワーク遅延により若干のズレが生じる可能性があります(通常は誤差1秒未満)。
- ブラウザの自動再生制限により、稀に音源再生がブロックされる場合があります。その場合もゲーム進行自体はサーバー時間で正しく進みます。
- 現状お題は1種類(山形県新庄市に関係する物)のみをゲーム全体で使用する設計です。
